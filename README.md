# Security Writeups

Welcome!

This repository is where I document my cybersecurity learning journey through practical labs, CTFs, vulnerable machines and security research.

Most of these writeups were originally created as personal notes while studying. Instead of leaving them scattered across my computer, I decided to organize everything here so they can also help anyone following a similar path.

---

## What you'll find here
```
[*] TryHackMe writeups
[*] Hack The Box writeups        (coming soon)
[*] CTF challenges
[*] Privilege escalation notes
[*] Enumeration techniques
[*] Exploitation walkthroughs
[*] Personal research
[*] Useful references and cheatsheets
```

Each writeup focuses on explaining **why** something works instead of simply listing commands to copy and paste.

---

## Goals

This repository has a few objectives:
```
└─ Document my progress
└─ Build a public knowledge base
└─ Improve my technical writing
└─ Practice explaining security concepts clearly
└─ Help other beginners who are learning alongside me
```

I'm constantly updating older writeups whenever I learn a better technique or discover a cleaner approach.
